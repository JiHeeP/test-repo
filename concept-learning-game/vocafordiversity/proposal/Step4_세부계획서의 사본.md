# [기획서] 다문화 학생 맞춤형 어휘 학습 프로그램: <어휘의 징검다리>
## Step 4. 문맥 적용형 음절 조립 (Contextual Syllable Assembly)

### 0. 예시
- 구현 파일: `04_game.jsx`

### 1. 기획 배경 및 학습 목표
핵심 문제 (Pain Point):
- 학습자가 단어 뜻은 알아도 문장 맥락에서 올바른 형태(활용형/철자)로 재구성하지 못함.
- 즉시 오답 판정 중심 UI는 초급 학습자의 불안을 높여 시도 횟수를 줄임.

학습 목표:
- 문맥 문장을 듣고 빈칸에 맞는 음절을 조립하여 단어 형태를 산출한다.
- 기본형(`dictionaryForm`)과 학습형(`targetWord`)의 차이를 문장 속에서 체득한다.
- Easy/Hard 난이도 분리로 혼합 수준 학급에서 동시 학습을 가능하게 한다.

설계 철학:
- "맞히는 순간보다, 조립해 보는 과정에서 배운다."

### 2. 프로그램 로직 및 흐름 (Process Logic)
화면 구성:
- [상황 아이콘] + [빈칸 포함 문장] + [음절 블록 풀]

학습 흐름:
- 인식: 문장과 아이콘을 보고 상황 파악.
- 추론: 빈칸에 들어갈 단어를 맥락으로 예측.
- 조립: 블록을 순서대로 선택해 슬롯 채움.
- 검증: 모든 슬롯이 채워진 뒤에만 정오답 판정(Delayed Feedback).

피드백 시스템:
- 정답: "참 잘했어요" + 완성 문장 TTS + 다음 문제 이동 버튼
- 오답: 흔들림 효과 + 오류 메시지 + 재시도 버튼(단계 재초기화)

### 3. 데이터셋 및 삽화 명세 (Content Spec)
개발팀은 `VOCAB_DATA`를 기준으로 문장/음절/방해블록을 구성한다.
디자인팀은 아이콘 가이드를 기반으로 추후 일러스트 확장이 가능하도록 설계한다.

데이터 필드:
- `dictionaryForm`: 기본형
- `targetWord`: 문맥 학습형
- `syllables`: 정답 음절 시퀀스
- `sentencePre` + `sentencePost`: 문장 프롬프트
- `definition`: 힌트 모달 뜻풀이
- `distractors`: Hard 모드용 방해 블록
- `imageIcon`: 상황 시각 단서

### 4. UI/UX 상세 설계 (Wireframe Description)
상단 영역 (Context Visual):
- 아이콘/삽화를 크게 제시해 문장 의미를 직관적으로 파악하도록 설계

중단 영역 (Text Prompt):
- `sentencePre + (슬롯) + sentencePost` 형식
- Easy 모드: 슬롯에 Ghost Text 표시
- Hard 모드: 슬롯 공란

하단 영역 (Interaction):
- 블록 풀에서 선택 → 슬롯 자동 채움
- 슬롯 클릭 시 블록 되돌리기 지원(검증 전)

보조 기능:
- 힌트 모달(`?`): 정답 텍스트는 숨기고 "아이콘 + 뜻풀이"만 제공
- 난이도 토글: EASY/HARD 즉시 전환

### 5. 개발 요청 사항 (To Developers)
- TTS 로직:
  - 초기 읽기: `sentencePre + 무엇 + sentencePost`
  - 정답 후 읽기: 완성 문장 전체 읽기
- 오답 재도전:
  - 즉시 정답 공개 금지
  - 재시도 버튼으로 단계 재초기화(블록 재셔플 포함)
- 상태 관리:
  - `isIncorrect`, `isComplete`, `shakeSlots`, `showHint` 분리 관리
