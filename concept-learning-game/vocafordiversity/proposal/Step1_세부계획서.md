# [최종 기획서] 다문화 학생 맞춤형 어휘 학습: <어휘의 징검다리>
## STEP 1. 다국어 지원 멀티모달 카드 (Multilingual Multimodal Flashcards)

### 0. 예시
- 구현 파일: `01_game.jsx`
- 핵심 화면: 언어 선택 → 카드 앞면(소리+이미지) → 카드 뒷면(뜻+예문+번역어)

### 1. 기획 배경 및 목표
학습 대상: 한국어 어휘력이 부족한 다문화(KSL) 및 중도입국 학생.

핵심 문제:
- 한국어 단일 설명만으로는 초급 학습자에게 인지 과부하가 발생.
- 텍스트 해독 중심 활동은 초기 진입 장벽이 높음.
- 학습자가 "안다/모른다"를 점검할 장치가 부족하면 복습 우선순위가 흐려짐.

해결 전략:
- 모국어 비계(L1 Scaffolding): 중국어/러시아어 번역어를 표제어 바로 아래에 보조 정보로 제공.
- 소리 우선(Audio-First): 카드 진입 시 한국어 TTS를 자동 재생해 발음-의미 연결을 우선 강화.
- 직관적 UX: 클릭(터치) 1회로 앞/뒤 전환, 하단 2버튼 평가로 조작 복잡도 최소화.
- 자기평가 루프: [몰라요] 응답 단어를 별도 덱으로 자동 수집해 즉시 재학습.

### 2. 학습 흐름 (User Flow)
언어 선택 (Onboarding):
- 시작 화면에서 [한국어], [중국어], [러시아어] 중 1개를 선택.
- 선택 언어에 따라 번역어 표시 규칙이 적용된 학습 세션 시작.

카드 학습 (Learning):
- 앞면: 아이콘 + 표제어 + 자동 TTS(단어 단독, 0.7배속).
- 뒷면: 표제어 + 뜻풀이 + 예문 + (선택 언어 번역어) + 자동 TTS(단어/뜻/예문, 0.85배속).

자기 평가 (Self-Assessment):
- [몰라요] 클릭: 해당 단어를 unknownDeck에 적재.
- [알아요] 클릭: 다음 카드로 이동.

결과 및 복습 (Review):
- unknownDeck이 있으면 "틀린 단어 복습하기"로 재학습 루프 진행.
- unknownDeck이 비어 있으면 Step 1 완료 상태로 종료.

### 3. 데이터 구조 (Data Structure)
학습 효과를 위해 10개 핵심 어휘에 대해 다국어/문맥 정보를 함께 매핑한다.

필수 어휘 (10개):
- 용액, 움직임, 번갈다, 입자, 방식, 설명, 영향, 관찰, 환경, 주제

데이터 필드 구성 (`VOCAB_DATA`):
- `id`: 단어 식별자
- `word`: 한국어 표제어
- `zh`: 중국어 번역
- `ru`: 러시아어 번역
- `def`: 한국어 뜻풀이
- `example`: 한국어 예문
- `icon`: 카드 시각 아이콘 컴포넌트
- `color`: 카드 배경색 코드

### 4. 화면 및 기능 상세 설계 (UI/UX Spec)
#### A. 시작 화면 (Language Selection)
- 타이틀: `<어휘의 징검다리> - Step 1`
- Action: 3개 언어 버튼 배치
  - 한국어 (기본)
  - 중국어 (중문 번역 노출)
  - 러시아어 (러시아어 번역 노출)

#### B. 카드 앞면 (Front - 인지)
구성:
- 중앙 대형 아이콘
- 한국어 표제어 대형 텍스트
- 자동 재생 기반 오디오 안내(수동 재생 버튼은 보조)

UX:
- 카드 탭 시 즉시 뒷면 전환
- 조작 부담을 줄이기 위해 별도 서브 메뉴 없이 단일 인터랙션 유지

#### C. 카드 뒷면 (Back - 이해)
레이아웃 순서 (위→아래):
- 표제어 + 오디오 버튼
- 번역어(조건부 노출)
  - `ko`: 번역 숨김
  - `zh`/`ru`: 해당 번역 노출
- 한국어 뜻풀이 박스
- 한국어 예문 박스(핵심어 하이라이트)
- 하단 이미지 재확인 영역
- 하단 고정 [몰라요] / [알아요] 버튼

#### D. 결과 모달 (Result Modal)
- Case 1 (완료): unknownDeck=0 → "완벽해요" + 다음 단계 안내
- Case 2 (복습 필요): unknownDeck>0 → "틀린 단어 복습하기" 제공

### 5. 기능 로직 (Functional Logic)
번역어 노출 로직:
- IF `language === 'ko'` → 번역 텍스트 미표시
- IF `language === 'zh' | 'ru'` → 해당 필드 노출

TTS 로직:
- 모든 음성은 한국어(`ko-KR`)로 재생
- 앞면: 단어 단독(0.7)
- 뒷면: 단어 + 뜻 + 예문(0.85)
- 카드 전환 시 기존 발화 취소 후 새 발화 재생

학습 루프:
- `deck` 전체 1회 완료 후 `unknownDeck` 존재 시 재학습 라운드 생성
- `unknownDeck` 비어질 때까지 반복 가능

### 6. 교육공학적 기대 효과 (Pedagogical Impact)
- 언어 전이(Language Transfer): 모국어 번역을 의미 앵커로 활용해 한국어 핵심어 이해 속도 향상.
- 이중 부호화(Dual Coding): 시각(아이콘) + 청각(TTS) + 문맥(예문) 동시 자극으로 기억 정착 강화.
- 메타인지 강화: 학습자 스스로 모르는 단어를 표시하고 즉시 복습하는 루프 제공.
- 정서적 안정: 배경 언어를 존중하는 UI로 초기 불안 감소 및 참여 지속성 향상.
