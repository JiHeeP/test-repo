## 1. 기획 의도 및 해결 과제 (Problem & Solution)
### 1.1. 핵심 문제 (Pain Points)
- 단어 정의 암기와 실제 개념 구분의 간극: 단어 뜻은 외워도 관련/비관련 예시를 구분하지 못함.
- 소거법 의존: 보기 수가 적으면 추측 정답이 가능해 학습 정확도 착시가 생김.
- 수준 격차: 같은 단어라도 일부 학생은 즉시 분류하고, 일부는 근거 없이 선택함.

### 1.2. 솔루션 목표 (Goal)
- 8개 보기 중 4개 선택 구조로 찍기 확률을 낮추고 개념 경계 판단을 유도.
- 힌트 1회/재시도 1회 정책으로 "도움은 주되 정답 의존은 제한"하는 스캐폴딩 설계.
- 공통 채점 규칙(2점/1점/0점)을 적용해 Step 2~5 학습 성취 데이터를 일관되게 수집.

## 2. 학습 콘텐츠 설계 (Content Strategy)
### 2.1. 학습 대상 어휘 (범교과 학습 도구어 9종)
- 재다, 표시, 측정, 정확히, 추측, 의미, 단서, 상황, 짐작

각 단어는 아래 풀로 구성:
- Good Pool: 관련어 10개
- Bad Pool: 비관련어 5개
- 라운드 생성 시 Good 4개 + Bad 4개를 샘플링하여 총 8개 보기 구성

## 3. 상세 기능 및 UX 시나리오 (UX Logic)
### 3.1. 화면 구성 (UI Layout)
상단 (Context Area):
- 핵심 단어 대형 표기
- 단어 듣기 버튼(TTS)

중단 (Selection Area):
- 8개 선택 카드(2열 또는 반응형 4열)
- 선택 수 카운터(현재 선택/필수 선택)

하단 (Control Area):
- 힌트 1회
- 선택 초기화
- 채점하기(재시도 시 "재시도 채점"으로 라벨 변경)

### 3.2. 상호작용 흐름 (Interaction Flow)
탐색 (Explore):
- 학생은 핵심 단어를 듣고 8개 보기를 읽어 관련어를 고름.

선택 (Selection):
- 최대 4개까지 선택 가능.
- 4개 초과 선택 시 제한 피드백 제공.

검증 (Validation):
- 4개를 정확히 선택한 상태에서만 채점 가능.
- 정답 시: 힌트 사용 여부에 따라 2점 또는 1점.
- 오답 시: 재시도 1회 제공, 재시도 실패 시 0점.

### 3.3. 스캐폴딩 시스템 (Scaffolding)
힌트:
- 미선택 정답 1개를 자동 선택 및 잠금.
- 힌트 사용 문제는 최대 1점으로 제한.

선택 초기화:
- 잠금된(힌트 제공) 카드는 유지하고 나머지 선택만 초기화.

점수 정책:
- 정답(힌트X): 2점
- 정답(힌트O): 1점
- 오답(최종): 0점

## 4. 기대 효과 (Educational Impact)
실질적 문해력 향상:
- 단어-예시 간 의미 연결을 반복하며 개념 범주를 정확히 형성.

메타인지 강화 (Anti-Fluency Illusion):
- 유사하지만 비관련인 단어를 배제하는 과정에서 혼동 지점을 스스로 확인.

정서적 안전장치:
- 힌트/재시도 정책으로 실패 비용을 조절하면서도, 최종 판단은 학습자에게 남김.

## 5. 추후 확장 계획 (Roadmap)
- Teacher Dashboard: 단어별 정답률/힌트 사용률/재시도율 리포트 제공.
- Custom Set: 교사가 주제어/관련어/비관련어 풀을 직접 입력해 맞춤 문제 생성.

| 1 | 재다 | 키, 몸무게, 자, 줄자, 길이 | 사과, 노래, 잠, 춤, 하늘 | 측정 행위와 무관 자극 분리 |
