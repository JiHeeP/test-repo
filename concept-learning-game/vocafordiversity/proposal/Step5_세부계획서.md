## 1. 기획 개요 및 배경
### 1.1. 기획 의도
배경:
- Step 1~4에서 형성한 어휘 지식을 "뜻 기반 선택(Meaning)"과 "문장 구성(Use)"으로 연결하는 통합 산출 단계가 필요함.

문제 정의 (Pain Point):
- 학습자가 단어를 눈으로 보면 고르지만(재인), 단어를 가린 상태에서 뜻과 문맥만으로는 선택을 어려워함.
- 문장 조립 시 틀린 어절을 스스로 교정하는 과정이 없으면 실제 쓰기 전이 효과가 낮음.

해결책:
- 2-stage 구조 도입
  - Stage 1: 블라인드 어휘 퀴즈(뜻 기반 선택)
  - Stage 2: 문장 어절 조립(통제 산출)

### 1.2. 타겟 유저
- 한국어 어휘력이 부족한 초등 다문화 학생 및 읽기/문장화가 약한 학습자.
- 의미 이해는 가능하지만 문장 적용 단계에서 오류가 잦은 학습자.

## 2. 교육공학적 설계 원리 (Pedagogy)
의미 우선 인출(Meaning-first Retrieval):
- Stage 1에서 핵심 단어를 `?????`로 숨겨 형태 단서 없이 의미로만 정답을 판단하게 함.

통제 산출(Controlled Production):
- Stage 2에서 정답/오답 카드 혼합 상태에서 문장 슬롯을 조립해, 문법적 위치와 어절 호응을 점검.

정교한 오답 교정:
- 채점 시 맞은 슬롯은 고정, 틀린 슬롯만 반환하여 부분 정답 기반 교정 학습 제공.

## 3. 핵심 기능 및 UX/UI 전략
### 3.1. 게임 메커니즘 (Core Loop)
Stage 1. 블라인드 어휘 퀴즈:
- 표시: 단어는 숨김(`?????`), 뜻은 강조 표시.
- 과제: 문장 빈칸에 맞는 어구를 2지선다로 선택.
- 오답 설계: 유사어/유사음 방해 선지 포함 (예: 방식/방석, 영향/영양).
- 점수: 정답 1점.

Stage 2. 문장 어절 조립:
- 표시: 핵심 단어 공개.
- 과제: 카드 뱅크(정답 어절 + 방해 어절)에서 슬롯 순서대로 배치.
- 채점: 정답 슬롯은 잠금, 오답 슬롯만 반환.
- 힌트: "함정 제거"로 방해 카드 1개 제거(사용 라운드 최대 1점).
- 점수: 힌트 미사용 정답 2점, 힌트 사용 정답 1점.

전환/완료:
- Stage 1 완료 시 전환 화면(점수 표시 + Stage 2 진입).
- Stage 2까지 완료하면 최종 점수 화면 제공.

### 3.2. UX/UI 디테일
- 진행 상태: 상단에 단계/문항 진행도와 점수 실시간 표시.
- 슬롯 힌트 라벨: "누가/언제/무엇을/어찌했나"로 문장 골격 인식 지원.
- 리셋 버튼: 잠금되지 않은 카드만 초기화.
- 피드백: 정답/오답 시 색상/애니메이션으로 즉시 반응.

## 4. 콘텐츠 데이터 구조 (Data Structure)
10개 핵심 단어를 아래 구조로 관리:
- `word`: 핵심어
- `meaning`: 정의
- `chunks`: 정답 문장 어절 배열
- `targetIndex`: Stage 1 정답 위치
- `vocabDistractor`: Stage 1 방해 선지
- `hints`: Stage 2 슬롯 문법 힌트
- `fullDistractors`: Stage 2 방해 어절

## 5. 기대 효과 (Expected Outcome)
- 의미 기반 산출력 강화: 단어 형태를 가린 상태에서도 뜻과 맥락으로 선택하는 능력 향상.
- 문장 구성 정확도 향상: 어절 순서/문법 기능을 슬롯 단위로 교정하며 문장 생산 정확도 증가.
- 메타인지 개선: 힌트 사용 여부와 오답 패턴을 통해 학습자가 취약 지점을 인식.
- 완주 경험 강화: Stage 분리와 전환 보상으로 난이도 상승을 자연스럽게 수용.
