# 레벨 4 재료 생성 프롬프트 - 음절 선택

## 게임 설명

문장 속 빈칸에 들어갈 단어를 **음절 블록**을 하나씩 눌러 완성하는 게임이다.

- 화면 위: `sentencePre` [빈칸 슬롯들] `sentencePost` 형태의 문장
- 화면 아래: 정답 음절 + 교란 음절이 섞인 블록 풀
- **쉬운 모드:** 빈칸 슬롯에 해당 음절이 흐리게(힌트로) 보임
- **어려운 모드:** 교란 음절이 섞여 있어 학생이 직접 골라야 함
- 학생이 마지막 슬롯을 채우는 순간 자동 채점
- 오답 시 슬롯이 흔들리고 다시 시도 가능

---

## 출력 데이터 구조

```js
{
  id: 1,
  dictionaryForm: "단어 사전형",   // 예) "번갈다"
  targetWord: "문장에 쓰인 활용형", // 예) "번갈아"
  syllables: ["음", "절", "1"],   // targetWord를 음절로 분해한 배열
  sentencePre: "빈칸 앞 문장",     // 예) "친구와 순서를 "
  sentencePost: " 놀아요.",        // 예) " 놀아요." (빈칸 뒤 문장)
  definition: "단어의 뜻",         // 힌트 모달에 표시
  distractors: ["교1", "교2"],    // 오답 음절 2개 (hard 모드에 추가)
  imageIcon: "🔄"                 // 의미를 나타내는 이모지 1개
}
```

### CSV 저장 형식 (vocab_review_checklist.csv 참고)
```
정답:음절1음절2... | 보기:음1/음2/음3/음4/음5
```
- `정답`: 단어 원형
- `보기`: 정답 음절 전체 + 교란 음절 2개를 `/`로 구분 (순서 무관)

## 각 필드 작성 기준

### targetWord (활용형)
- 실제 문장에서 자연스럽게 쓰이는 형태
- 명사는 사전형 = 활용형 (예: 영향, 주제)
- 동사/형용사는 적절한 어미를 붙인다 (예: 번갈다 → 번갈아)
- **음절 수가 너무 많으면 학생이 부담감을 느낀다.** 2~4음절 권장

### sentencePre / sentencePost
- 초등학교 3~5학년이 이해할 수 있는 짧은 문장 (전체 10어절 이하)
- 목적어/부사어 자리에 단어를 배치하여 `~을/를` `~이/가` 형태가 자연스럽게 이어지도록
- sentencePre는 공백으로 끝나는 것이 자연스럽다 (예: `"날씨는 우리 생활에 "`)
- sentencePost는 조사로 시작하는 경우 앞에 공백 없이 붙인다 (예: `"이 빨라요."`)

### distractors (교란 음절) — 2개
교란 음절의 역할: 정답 음절과 시각적·청각적으로 유사하여 학생이 혼동할 수 있는 음절
선정 기준:
1. **모양 유사**: 자모 구성이 비슷한 음절 (예: 영→양, 향→앙)
2. **소리 유사**: 발음이 비슷한 음절 (예: 갈→라, 번→반)
3. **해당 단어의 다른 활용 음절 재활용**: 정답 단어 안에서 자주 혼동하는 음절 (예: 번갈아의 distractors에 "다" 사용)
- 교란 음절은 **정답 음절 배열에 포함되지 않아야** 한다.
- 총 보기 = syllables + distractors = 최소 4개 블록

### imageIcon
- 단어 의미를 직관적으로 전달하는 이모지 1개
- 추상 명사는 관련 행동·맥락 이모지로 표현
  예) 추측 → 🔍, 단서 → 🔑, 영향 → ☀️

## 입력 형식

아래 어휘 목록을 보고, 각 단어에 대해 레벨 4 재료를 생성하라.

```
어휘 목록:
- 단어1 : 뜻1
- 단어2 : 뜻2 (동사인 경우 활용형 힌트 포함 가능)
...
```

## 프롬프트 (AI에게 전달할 텍스트)

```
당신은 초등학생 어휘 교육 전문가이자 국어 교사입니다.
아래 어휘 목록에 대해 '레벨 4 음절 선택' 게임 재료를 생성해 주세요.

[게임 설명]
학생은 문장 속 빈칸에 들어갈 단어를 음절 블록을 하나씩 눌러 완성합니다.
블록 풀에는 정답 음절과 교란 음절이 섞여 있습니다.

[생성 조건]
1. dictionaryForm: 사전에 등재된 단어 원형
2. targetWord: 예문에서 실제로 쓰인 활용형 (명사는 원형 그대로, 동사/형용사는 어미 활용)
3. syllables: targetWord를 음절 단위로 분해한 배열 (2~4음절 권장)
4. sentencePre / sentencePost: 초등 3~5학년 수준의 자연스러운 예문 (전체 10어절 이하)
   - 빈칸이 문장 중간(목적어·부사어 위치)에 오도록 작성
   - 한 단어를 제거해도 문장이 의미적으로 완결되어야 함
5. definition: 단어의 핵심 뜻 (한 문장, 15자 이내)
6. distractors: 교란 음절 2개
   - 정답 음절과 모양 또는 소리가 유사한 음절
   - 정답 syllables 배열에 포함되지 않는 음절
7. imageIcon: 의미를 나타내는 이모지 1개 (추상어는 맥락 이모지 사용)

[출력 형식 - JSON 배열, id는 1부터 순서대로]
[
  {
    "id": 1,
    "dictionaryForm": "단어 사전형",
    "targetWord": "문장 활용형",
    "syllables": ["음1", "절2"],
    "sentencePre": "빈칸 앞 문장 ",
    "sentencePost": "이/를/은 뒤 문장.",
    "definition": "핵심 뜻 (15자 이내)",
    "distractors": ["교란1", "교란2"],
    "imageIcon": "🔍"
  },
  ...
]

[어휘 목록]
- {{단어1}} : {{뜻1}}
- {{단어2}} : {{뜻2}}
...

각 단어에 대해 위 형식에 맞는 JSON을 작성해 주세요.
설명 없이 JSON만 출력하세요.
```

## 검수 체크리스트

생성 후 아래 항목을 반드시 확인한다.

- [ ] syllables를 합쳤을 때 targetWord와 정확히 일치하는가?
- [ ] sentencePre + [targetWord] + sentencePost가 자연스러운 한국어 문장인가?
- [ ] 빈칸이 목적어·부사어·서술어 자리에 있는가? (조사가 자연스럽게 이어지는가?)
- [ ] distractors 2개가 syllables 배열에 없는 음절인가?
- [ ] distractors가 정답 음절과 모양·소리가 유사하여 실제로 혼동을 줄 수 있는가?
- [ ] definition이 15자 이내이고 핵심 뜻만 담고 있는가?
- [ ] imageIcon이 단어 의미와 연결되는가?
- [ ] 문장이 초등 3~5학년 수준인가? (어려운 어휘, 복잡한 구문 없음)
- [ ] 동사·형용사의 경우 targetWord 활용형이 문법적으로 올바른가?
