# 어휘의 징검다리 - 레벨별 재료 생성 프롬프트 개요

## 게임 구조 요약

**어휘의 징검다리**는 초등학생 대상 5단계 어휘 학습 게임이다.
이 폴더는 **레벨 3·4·5**의 게임 재료를 AI로 생성하기 위한 프롬프트 모음이다.

---

## 레벨별 게임 설명

### 레벨 3 - 관련어 고르기 (`01_level3_관련어.md`)
- 핵심 단어 1개를 제시하고, 8개 보기 중 관련 단어 4개를 선택
- 보기 = 정답 후보(good) 4개 + 오답(bad) 4개 무작위 추출
- **필요 재료:** `good` 후보 10개, `bad` 후보 5개

### 레벨 4 - 음절 선택 (`02_level4_음절선택.md`)
- 문장 속 빈칸에 알맞은 음절 블록을 순서대로 배치
- 쉬운 모드: 흐린 글자로 힌트 제공 / 어려운 모드: 교란 음절 혼합
- **필요 재료:** 음절 분해, 예문(전/후), 뜻, 교란 음절 2개, 이모지

### 레벨 5 - 어절 조립 (`03_level5_어절조립.md`)
- **1단계:** 뜻만 보고 빈칸에 알맞은 어절 고르기 (2지선다)
- **2단계:** 어절 카드를 올바른 순서로 배치하여 문장 완성
- **필요 재료:** 4개 어절(완성 문장), 정답 어절 위치(targetIndex), 뜻 교란지(vocabDistractor), 힌트 레이블 4개, 문장 교란지(fullDistractors) 2개

---

## 공통 채점 기준

| 상황 | 점수 |
|------|------|
| 힌트 없이 정답 | 2점 |
| 힌트 사용 후 정답 | 1점 |
| 오답 | 0점 |

- 힌트 1회, 재시도 1회 정책 적용
- 단어당 최대 10점 (5단계 × 2점)

---

## 사용 방법

1. 어휘 목록을 준비한다 (단어 + 뜻 최소)
2. 해당 레벨 프롬프트 파일을 열어 `[입력 형식]` 섹션에 어휘를 채운다
3. AI(Claude 등)에게 전달하여 재료를 생성받는다
4. 생성된 결과를 게임 코드의 `VOCAB_DATA` / `GAME_DATA` 배열에 삽입한다
