# 레벨 3 재료 생성 프롬프트 - 관련어 고르기

## 게임 설명

핵심 단어 1개를 화면에 보여 주고, 8개 보기(정답 후보 4개 + 오답 4개) 중에서
그 단어와 관련된 단어 4개를 학생이 고르는 게임이다.

- 매 라운드마다 `good` 풀에서 4개, `bad` 풀에서 4개를 무작위로 뽑아 섞어 제시한다.
- `good`이 최소 10개 있어야 매번 다른 조합이 가능하다.
- `bad`는 최소 5개 있어야 다양한 오답 조합이 가능하다.
- 힌트 버튼 클릭 시 `good` 중 1개를 자동 선택해 준다.

---

## 출력 데이터 구조

```js
{
  word: '단어',           // 핵심 어휘 (화면에 크게 표시됨)
  good: [               // 관련어 후보 (10개 이상)
    '관련어1', '관련어2', ...
  ],
  bad: [                // 무관련어 후보 (5개 이상)
    '오답1', '오답2', ...
  ],
}
```

## good / bad 선정 기준

### good (관련어) — 충족 조건 중 2개 이상 해당
1. **의미 연상** : 단어 뜻에서 직접 연상되는 대상·행위·도구
   예) '측정' → 온도계, 저울, 체온, 숫자
2. **상황·맥락** : 그 단어를 쓰는 전형적인 상황에 등장하는 요소
   예) '단서' → 탐정, 발자국, 수수께끼
3. **공기어(콜로케이션)** : 학습자가 자주 접하는 연어 파트너
   예) '추측' → 아마도, 생각하기, 물음표
4. **기능어/동작** : 해당 행위와 연결되는 동작·상태어
   예) '재다' → 맞추다, 눈금
- **주의:** good 단어끼리는 서로 다른 의미 범주에서 골고루 분포해야 한다.

### bad (무관련어) — 충족 조건
1. **완전히 무관** : 단어의 뜻·상황과 전혀 연결되지 않는 단어
2. **학생이 그럴싸하다고 느낄 수 있는 것** : 너무 황당하면 쉽게 걸러짐
   예) '재다'의 bad: 사과·노래·잠 (일상적이지만 재는 것과 무관)
3. **문화적 편향 없음** : 특정 지역·성별·가정환경을 연상시키지 않는 단어

## 입력 형식

아래 어휘 목록을 보고, 각 단어에 대해 레벨 3 재료를 생성하라.

```
어휘 목록:
- 단어1 : 뜻1
- 단어2 : 뜻2
...
```

## 프롬프트 (AI에게 전달할 텍스트)

```
당신은 초등학생 어휘 교육 전문가입니다.
아래 어휘 목록에 대해 '레벨 3 관련어 고르기' 게임 재료를 생성해 주세요.

[게임 규칙]
- 학생은 핵심 단어를 보고, 8개 보기 중 관련 단어 4개를 고릅니다.
- 보기는 정답 후보(good)에서 4개, 오답(bad)에서 4개를 무작위로 뽑아 제시합니다.

[생성 조건]
1. good: 핵심 단어와 의미적으로 관련된 단어·구 10개
   - 의미 연상, 사용 맥락, 콜로케이션, 관련 행위에서 골고루 선정
   - 2~4자 이내의 짧은 단어 또는 구
   - 초등학생이 알 수 있는 수준
   - 10개 중 무작위 4개를 뽑아도 모두 정답으로 인정 가능해야 함
2. bad: 핵심 단어와 전혀 무관한 단어 5개
   - 너무 황당하지 않고, 학생이 잠깐 헷갈릴 법한 일상 단어
   - 문화적 편향 없음

[출력 형식 - JSON 배열]
[
  {
    "word": "단어",
    "good": ["관련어1", "관련어2", "관련어3", "관련어4", "관련어5", "관련어6", "관련어7", "관련어8", "관련어9", "관련어10"],
    "bad": ["오답1", "오답2", "오답3", "오답4", "오답5"]
  },
  ...
]

[어휘 목록]
- {{단어1}} : {{뜻1}}
- {{단어2}} : {{뜻2}}
...

각 단어에 대해 위 형식에 맞는 JSON을 작성해 주세요.
설명 없이 JSON만 출력하세요.
```

## 검수 체크리스트

생성 후 아래 항목을 반드시 확인한다.

- [ ] good 10개가 모두 실제로 그 단어와 관련되는가?
- [ ] good 10개 중 어느 4개를 뽑아도 정답 세트로 타당한가?
- [ ] bad 5개가 핵심 단어와 무관한가?
- [ ] bad가 너무 쉽게 걸러지는 황당한 단어는 아닌가?
- [ ] 모든 단어가 초등학생 어휘 수준인가?
- [ ] 문화적 편향(특정 음식, 지역, 성별 고정관념)은 없는가?
- [ ] good과 bad 사이에 겹치는 단어는 없는가?
