# 레벨 5 재료 생성 프롬프트 - 어절 조립

## 게임 설명

2단계로 구성된 고차원 어휘 활용 게임이다.

### 1단계 — 낱말 퀴즈 (Blind Mode)
- 단어는 `?????`로 가려지고, 뜻만 화면에 표시된다.
- 단어가 들어간 문장의 빈칸 위치에 2개의 어절 선택지가 제시된다.
  - 선택지 A: `chunks[targetIndex]` (정답 어절)
  - 선택지 B: `vocabDistractor` (의미·발음이 유사한 오답 어절)
- 학생은 뜻을 보고 맥락에 맞는 어절을 고른다.
- 정답 시 1점 획득 후 2단계로 이동.

### 2단계 — 문장 조립 (Sentence Builder)
- 단어가 공개되고, 4개의 정답 어절 카드 + 2개의 교란 어절 카드가 섞여 제시된다.
- 학생은 카드를 순서대로 배치하여 완성 문장을 만든다.
- 채점 시 틀린 위치의 카드만 반환하고 맞은 위치는 잠근다(초록 표시).
- 힌트 사용 시 교란 카드 1개를 제거해 준다 (힌트 사용 = 최대 1점).
- 모든 슬롯이 정확히 채워지면 2점(힌트 없음) 또는 1점(힌트 사용).

---

## 출력 데이터 구조

```js
{
  id: 1,
  word: "핵심 어휘",             // 1단계에서 ?????로 표시, 2단계에서 공개
  meaning: "단어의 뜻",          // 1단계에서 크게 강조 표시 (20자 이내)
  chunks: [                     // 완성 문장을 이루는 4개 어절 배열
    "어절1",                    // 주어부 (누가/무엇이)
    "어절2",                    // 부사어 (언제/어디서/어떻게)
    "목표어절",                  // targetIndex 위치, 목적어부 (무엇을) — 핵심 단어 포함
    "어절4"                     // 서술어 (어찌했나)
  ],
  targetIndex: 2,               // chunks에서 핵심 단어가 포함된 어절의 인덱스 (보통 2)
  vocabDistractor: "오답어절",   // 1단계용: targetIndex 위치에 넣을 오답 어절
  hints: ["누가?", "언제?", "무엇을?", "어찌했나?"],  // 2단계 슬롯 힌트 레이블
  fullDistractors: ["교란1", "교란2"]  // 2단계용: 문장에 없는 교란 어절 2개
}
```

### CSV 저장 형식 (vocab_review_checklist.csv 참고)
```
chunks:어절1/어절2/어절3/어절4 | targetIndex:2 | vocabDistractor:오답어절 | hints:힌트1/힌트2/힌트3/힌트4 | fullDistractors:교란1,교란2
```

  fullDistractors: ["몸무게 측정이", "놀러 갔다."] },

## 각 필드 작성 기준

### chunks (4개 어절)
문장을 **4개 의미 단위(어절)**로 나눈다.

| 위치 | 역할 | 예시 |
|------|------|------|
| 0 | 주어부 (누가/무엇이) | "나는", "우리는", "날씨는" |
| 1 | 부사어 (언제/어디서/왜/어떻게) | "체육 시간에", "양호실에서", "미래를 위해" |
| 2 | 목적어부 (무엇을) — **핵심 단어 포함** | "친구의 움직임을", "큰 영향을" |
| 3 | 서술어 (어찌했나) | "관찰했다.", "준다.", "만든다." |

- 목적어부(index 2)에 핵심 단어를 배치하고 `을/를` 조사를 붙인다.
- 전체 문장이 초등 3~5학년 수준이어야 한다.
- 4개 어절을 이어 붙이면 완전한 문장이 완성되어야 한다.

### targetIndex
- 거의 항상 `2` (목적어 어절 위치)
- 서술어에 핵심 단어가 포함되는 예외적 경우만 `3`

### vocabDistractor (1단계 오답 어절)
- `chunks[targetIndex]`와 **동일한 조사**를 사용하되 핵심 단어를 **유사 단어**로 교체
- 유사 기준:
  1. **소리 유사** (발음이 비슷): 영향→영양, 측정→걱정, 환경→안경
  2. **의미 유사** (뜻이 가까워 맥락 판단 필요): 움직임→믿음 (같은 어미 `을`)
  3. **형태 유사** (글자가 비슷): 단서→단추, 방식→방석
- **반드시 문장의 빈칸에 들어갔을 때 문법적으로는 어색하지 않아야** 의미 변별력이 생긴다.

### hints (4개 힌트 레이블)
- chunks 4개 각각에 대한 질문 레이블
- 기본 패턴: `["누가?", "언제?", "무엇을?", "어찌했나?"]`
- 부사어 종류에 따라 변형:
  - 장소 부사어: "어디서?"
  - 이유 부사어: "왜?"
  - 방법 부사어: "어떻게?"
  - 대상 부사어: "어디에?"

### fullDistractors (2단계 교란 어절) — 2개
2단계 문장 조립 시 카드 풀에 섞이는 교란 어절이다.
- **교란1**: `chunks[targetIndex]`와 **조사만 다른** 버전 (을→이, 를→가)
  예) "큰 영향을" → "큰 영향이"
- **교란2**: `chunks[3]`(서술어)을 **의미·문맥상 맞지 않는 동사**로 교체
  예) "준다." → "받는다.", "관찰했다." → "무시했다."
- 두 교란 어절은 각각 문법적으로는 성립하지만 문장 맥락에 맞지 않아야 한다.

당신은 초등학생 어휘 교육 전문가이자 국어 교사입니다.
아래 어휘 목록에 대해 '레벨 5 어절 조립' 게임 재료를 생성해 주세요.

[게임 설명]
1단계: 단어가 가려진 상태에서 뜻만 보고, 빈칸에 들어갈 어절을 2개 중 고릅니다.
2단계: 단어가 공개되고, 4개 정답 어절 카드 + 2개 교란 카드를 순서대로 배치해 문장을 완성합니다.

[문장 구성 원칙]
- 4개 어절: [주어부] [부사어] [목적어부—핵심단어 포함] [서술어]

- 전체 문장은 초등 3~5학년이 이해할 수 있는 수준.

[생성 조건]
1. word: 핵심 어휘
2. meaning: 단어의 핵심 뜻 (20자 이내, 1단계에서 크게 표시됨)

5. vocabDistractor: 1단계 오답 어절
   - chunks[targetIndex]와 같은 조사를 쓰되, 핵심 단어를 소리/의미/형태가 유사한 단어로 교체

   예) ["누가?", "언제?", "무엇을?", "어찌했나?"]

[출력 형식 - JSON 배열, id는 1부터 순서대로]

    "id": 1,
    "word": "핵심단어",
    "meaning": "단어 뜻 (20자 이내)",
    "chunks": ["어절1", "어절2", "목적어+핵심단어+조사", "서술어."],
    "targetIndex": 2,

## 검수 체크리스트

생성 후 아래 항목을 반드시 확인한다.

### 문장 구조 검수
- [ ] chunks 4개를 이어 붙이면 완전하고 자연스러운 문장인가?
- [ ] chunks[targetIndex]에 핵심 단어가 포함되어 있는가?
- [ ] chunks[targetIndex]에 `을/를` 조사가 붙어 있는가?
- [ ] 문장이 초등 3~5학년 수준인가?

### 1단계 (vocabDistractor) 검수
- [ ] vocabDistractor가 chunks[targetIndex]와 **같은 조사**를 쓰는가?
- [ ] 핵심 단어를 대체한 단어가 소리·의미·형태 면에서 유사한가?
- [ ] vocabDistractor를 문장에 넣었을 때 문법은 성립하나 의미가 달라지는가?
- [ ] 학생이 뜻을 모르면 vocabDistractor를 고를 만큼 헷갈리는가?

### 2단계 (fullDistractors) 검수
- [ ] fullDistractors[0]이 chunks[targetIndex]에서 조사만 바뀐 형태인가?
- [ ] fullDistractors[1]이 서술어 맥락에 맞지 않는 동사인가?
- [ ] 두 교란 어절이 문장 안에서 학생을 실제로 혼동시킬 수 있는가?

### hints 검수
- [ ] hints 4개가 chunks 4개의 역할을 적절히 표현하는가?
- [ ] 부사어의 성격에 맞는 레이블을 사용했는가? (언제/어디서/왜/어떻게/어디에)
