## 요구사항 1 — Step01: 이미지 교체 검토

**논의 필요 사항**

- `public/images/` 또는 `src/assets/` 어느 경로에 넣을 것인지

## 요구사항 2 — Step03: 단어 읽기 순서 변경

**현재 상태**
- "단어 듣기" 버튼 클릭 시 핵심 단어(word)만 TTS로 읽음
- 8개 선택지는 읽지 않음
- 파일: `src/games/Step03.jsx`

**요구사항**
"단어 듣기" 클릭 시 다음 순서로 읽기:

1. 핵심 단어 읽기 (예: "관찰")
2. 8개 선택지를 화면 배치 순서대로 순차 읽기
   - 1열 왼쪽 → 오른쪽 (위쪽 4개)
   - 2열 왼쪽 → 오른쪽 (아래쪽 4개)

**예시**
```
[탐구] [관찰] [분석] [실험]     ← 이 순서대로 읽기
[공부] [연구] [확인] [이해]     ← 이어서 이 순서대로 읽기
```

## 요구사항 3 — Step05: 2단계 구조 확인

**현재 상태**
- 1단계: 문장에서 핵심 단어 선택 (2지선다)
- 2단계: 문장 전체를 단어 블록으로 조립 (드래그앤드롭)
- 파일: `src/games/Step05.jsx`

**요구사항**
- 두 단계 구조 자체는 유지
- 단, 아래 요구사항 4에 따라 1단계 문제 데이터를 수정해야 함

---

## 요구사항 4 — Step05 1단계: 빈칸 위치 수정 (핵심)

**현재 상태**
- 문장을 chunks 배열로 쪼개어 `targetIndex` 위치의 chunk 전체가 빈칸
- 예: chunks = ["나는", "수학 시간에", "자로 길이를 재어 보았다."] → targetIndex=2가 빈칸
- 핵심 단어가 아닌, 핵심 단어를 포함한 구절 전체가 빈칸이 되는 문제 발생
- 파일: `src/games/Step05.jsx` (GAME_DATA, line 4-15)

**요구사항**
빈칸은 반드시 뜻이 위에 제시된 **핵심 단어 자체**여야 함

**예시 — 단어: 재다**

| 구분 | 내용 |
|------|------|
| 핵심 단어 | 재다 |
| 제시되는 뜻 | 길이, 크기, 양 등을 측정하다 |
| 현재 문제 | 나는 수학 시간에 `(          )재어 보았다.` |
| 수정 문제 | 나는 수학 시간에 자로 길이를 `(          ).` |
| 정답 선택지 | 재어 보았다 |
| 오답 선택지 | 세어 보았다 |

**수정 방향**
- `GAME_DATA`의 각 문제에서 문장 내 핵심 단어 동사/술어가 빈칸이 되도록 재구성
- `chunks` 배열과 `targetIndex`, `vocabDistractor` 데이터 수정 필요
- 핵심 단어의 활용형(예: "재어 보았다")이 선택지로 들어가야 함
