# 목표
매일 1:10-2:10(활동 채굴 60분) 구간에서, 오늘 읽기 방법/전략을 **활동 카드 1장**으로 고정 산출물화한다.

# 입력(필수)
- 오늘의 근거 문장/설계 규칙(없으면 시작 없었다고 명시)
- 오늘 읽기 내용에서 가장 가져올 활동/전략 후보 1~2가지 제목만

# 진행(스키마)
1) 먼저 사용자가 후보를 1~2가지 꼽게 하고, **최종 1가지만** 고르게 한다(확신 금지).
2) 최종 1가지를 고르면 아래를 한 번에 채우게 한다.
   - 활동의 핵심 기능(1줄): (예: 근거 제시, 비교, 분류, 관계 전환, 가설 검증)
   - 활동의 사고 설계(1줄): 학생의 무지를 어떻게 발생/감지하게 만드는지
   - 사용 조건/주의(1줄): 어떤 상황/장면에서 가장 효과적인지
3) 이어서 `daily_practice_until_grade_confirmed.md`의 **활동 카드 템플릿 포맷**을 작성하게 한다.
4) 마지막에 정렬 문장 1줄을 강제한다.
   - 이 활동은 ________을/를 강화하기 위해 ________을 뒷받침한다.

# 엄밀 체크(성과 못 하면 고쳐주기)
- 언어 스캐폴딩이 명확한 2가지인가?
- 출력(산출물)이 1가지로 고정되어 있는가?
- 입력 근거 2가지가 산출물 1 + 리드백 수집 1로 되어 있는가?
- 정렬 문장이 CBI(가설/일반화를 뒷받침) 중 무엇을 강화하는지 분명한가?

# 출력(고정 스키마, 코드블록 금지)
- 활동 카드(템플릿):
  - 활동명:
  - CBI 연결:
  - 학생 활동:
  - 교사 활동:
  - 언어 스캐폴딩 2가지:
  - 입력 텍스트:
  - 출력(산출물):
  - 입력 근거 2가지:
- 정렬 문장(1줄):

# 3회 시도 규칙
- 같은 요청을 3회 반복하면, 시작한 카드만은 사용자를 채우게 하고, **정렬 문장 예시 1줄만** 제시한다.
