> **자료**: 개념 기반 탐구학습의 실천 — 전이 가능한 이해의 촉진 전략 (Carla Marschall, Rachel French)
> **대화 날짜**: 2026-02-23

## 1단계: 이해 확인

### 다룬 핵심 개념

- **강력한 일반화의 요소**: 현재형 시제(과거형/미래형이면 "언제나 참"이 약해짐), 능동태, 2개 이상 개념, 가치 판단에서 자유로운 서술(가치 판단이 들어가면 일반화 불가 — "권리 제한이 당연하다" 같은 표현은 객관성 상실)
- **전략들의 공통점**: 개념 은행, 스피드 연결, 개념 매핑, 패턴 찾기 모두 **"개념을 먼저 충분히 이해 → 개념 간 관계 발견 → 일반화 문장 작성"**이라는 동일한 사고 경로를 밟음. 도구만 다를 뿐.

### 새롭게 명확해진 점

- 일반화의 **수동태 문제**: "보장된다", "보호될 수 있다"는 관계의 역동성이 떨어짐 → "보장한다", "촉진한다"로 능동 전환 필요
- **역동적 동사**의 중요성: 촉진한다, 결정한다, 확장시킨다, 제한한다, 변환한다 등 → cbi-generalization-coach의 가점 트리거
- **마이크로 일반화의 역할**: 작은 범위의 일반화 → 반복 → 거시 일반화로 확장하는 발판

### 논의 내용 요약

- **개념적 렌즈 탐색**: Erickson의 단일 렌즈 vs IB PYP의 Key Concepts + Related Concepts 비교
- **PYP Key Concepts 7가지**: Form, Function, Causation, Change, Connection, Perspective, Responsibility
  - PYP에서 Key Concepts는 탐구의 방향을 잡는 큰 렌즈(항상 7개 중 선택), Related Concepts는 단원 내용에 맞는 구체적 렌즈
  - Erickson 모델은 이를 구분하지 않고 "개념적 렌즈" 하나로 사용
- **렌즈 선택**: 책임(Responsibility) + 인과(Causation) + 기능(Function)으로 결정
  - "변화(Change)"는 인과 안에 포함
  - 단원 흐름: 인과(왜) → 기능(어떻게) → 책임(무엇을 해야 하는가)
- **PYP 초학문적 주제**: '법과 인권'은 "Sharing the Planet (지구를 함께 나누기)"에 해당
  - 해당 주제의 Related Concepts: Interdependence, Connection, Habitat, Rights, Responsibility, Peace/Conflict, Change, Survival

### 개념 매핑 구조

```
대개념: 인권
  ├─ 보장 ─── 헌법, 법, 존엄, 자유와 평등, 권리와 의무
  ├─ 침해 ─── 차별, 소수자
  └─ 보호 ─── 사회구성원, 관심
```

- 총 10개 개념, 5학년 수준에 적당
- 순서: 전체 논의로 대개념 → 수준 파악 후 중위 개념 탐색 → 하위 개념 배치 → 연결 & 일반화

### 주요 활동 (5차시)

**1차시: 인과 — 인권의 탄생**
- 활동: "인권이 없던 시대" 사례 조사 (아동 노동, 차별 역사)
- 기능: 사례 조사, 원인-결과 분석
- 도달 일반화: G2

**2차시: 인과 → 기능 — 왜 법이 필요한가**
- 활동: "인권 침해가 반복되자 만들어진 법" 사례 비교 (아동권리협약, 장애인차별금지법 등)
- 기능: 원인-결과 분석, 비교·판단
- 도달 일반화: G3

**3차시: 기능 — ★ 노키즈존 토론 ★**
- 활동: "노키즈존은 인권 침해인가?" 찬반 토론
  - 사장님의 권리: 영업의 자유, 다른 손님의 편의
  - 아이/가족의 권리: 이동의 자유, 차별받지 않을 권리
- 기능: 토론, 비판적 판단, 관점 취하기
- 도달 일반화: G4

**4차시: 책임 — 침해 사례 탐구 & 해결 방안**
- 활동: 모둠별 일상 속 인권 침해 사례 조사 → 원인 분석 → 구제 방법 탐색 → 해결 방안 제안
- 기능: 사례 조사, 원인-결과 분석, 해결 방안 탐색
- 도달 일반화: G5

**5차시: 책임 — 거시 일반화 도달 & 실천**
- 활동: 개념 매핑 완성 → 거시 일반화 도출 → "인권 보호 선언문" 또는 캠페인 포스터 제작
- 기능: 참여·실천
- 도달 일반화: ★ G1 (거시)

### 학생이 수행해야 할 기능 정리

| 분류 | 기능 | 적용 차시 |
|------|------|----------|
| 사고 기능 | 비교·대조하기, 원인-결과 분석하기, 관점 취하기, 비판적 판단하기, 분류하기, 패턴 찾기 | 1~4차시 |
| 탐구 기능 | 사례 조사하기, 자료 수집·정리하기, 질문 만들기, 증거 기반 주장하기 | 1~2, 4차시 |
| 의사소통 기능 | 토론·논증하기, 발표하기, 경청하기 | 3차시 |
| 사회적 기능 | 공감하기, 협업하기, 해결 방안 제안하기, 참여·실천하기 | 4~5차시 |

### 단원 흐름도

```
[인과] 왜 인권이 생겨났는가?
  G2: 존엄의 인식 → 인권 형성, 사회 변화 → 범위 확장
  G3: 질서 유지를 위해 법과 제도를 만들고 발전시킨다
        ↓
[기능] 권리가 부딪힐 때 어떻게 하는가?
  G4: 권리 충돌 → 토론과 합의로 균형점 (★노키즈존 토론)
        ↓
[책임] 우리는 무엇을 해야 하는가?
  G5: 관심 + 행동 → 침해 예방, 권리 회복
        ↓
  ★ G1 (거시): 인권 보호의 책임은 모두에게 있다
```

### 평가 아이디어

- **형성평가**: 각 차시별 일반화 도달 여부 확인 (Exit Ticket, 일반화 기록 차트)
- **총괄평가**: 인권 보호 선언문/캠페인 포스터에서 거시 일반화(G1)의 증거가 드러나는지 평가

## 더 탐구할 거리

- 노키즈존 토론을 실제로 해보면 학생들의 반응은 어떨지 — 5학년 수준에서 '권리 충돌' 개념을 어디까지 소화할 수 있는가
- 개념 매핑 10개 → 학생 수준에 따라 7~8개로 줄일 필요가 있을 수도 있음
- 이 단원의 일반화를 9장(전이하기)의 Stress Test로 검증하는 활동 설계
- PYP의 Key Concepts + Related Concepts 층위 구조를 한국 교육과정에 체계적으로 매핑하는 작업
- '변화(Change)' 렌즈를 독립 주제로 뺄 경우, 인권의 역사적 확장 과정(여성 참정권, 아동 권리 등)을 더 깊이 다룰 수 있음
