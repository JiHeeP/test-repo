## 수업 개요

- **핵심 질문 (Essential Question)**: 지형은 사람들의 생활 모습을 어떻게 바꾸는가?
- **핵심 일반화 (Generalization)**: 지형은 사람들의 생활 모습에 영향을 준다
- **예상 차시**: 1차시 (단원 마무리 전이 활동)
- **전제 조건**: 각 지형(산지, 평야, 해안 등)에 따른 생활 모습(교통, 음식, 직업, 여가, 경제)을 사전에 충분히 학습한 상태

---

## 차시 흐름

### 전반부: 위태로운 일반화 테스트 (약 20분)

- **목표**: 학생이 일반화를 비판적으로 검토하고, 근거를 들어 판단할 수 있다
- **활동**:
  1. 모둠별로 5개 일반화 카드 배부
  2. 동의/비동의 판에 카드 분류
  3. "우리 모둠은 ~한 이유로 ~에 동의/비동의합니다" 문장 틀로 근거 발표
  4. 전체 공유 후 수정 기회 부여
- **준비물**: 일반화 카드 5장(모둠 수만큼), 동의/비동의 분류판

**일반화 카드 내용:**

| 번호  | 문장                       | 유형             |
| --- | ------------------------ | -------------- |
| 1   | 지형은 사람들의 생활 모습에 영향을 준다   | 잘된 일반화         |
| 2   | 사람들은 지형에 맞게 생활 방식을 변화시킨다 | 잘된 일반화         |
| 3   | 지형에 따라 얻는 경제적 이익이 달라진다   | 약한 일반화 (오류)    |
| 4   | 평야가 넓은 지역일수록 인구가 많다      | 약한 일반화 (반례 존재) |
| 5   | 산이 많은 나라는 발전하기 어렵다       | 약한 일반화 (편견)    |

### 후반부: "만약에 ~라면" 수행평가 (약 20분)

- **목표**: 일반화를 새로운 가정적 상황에 적용하여 생활 변화를 예측할 수 있다
- **활동**:
  1. 질문 제시: "만약 우리 동네가 사방이 바다로 둘러싸인 섬이 된다면, 우리의 생활 모습은 어떻게 달라질까?"
  2. 개별 작성 (5개 영역 중 3개 이상 선택하여 예측)
  3. 짝 공유 → 보완
  4. 전체 발표 및 정리
- **준비물**: 활동지 (영역별 예측 작성란 + "~이기 때문에" 근거란 포함)

**활동지 구조 예시:**

| 생활 영역 | 어떻게 달라질까? | 왜 그렇게 생각하나? (근거) |
|-----------|-----------------|--------------------------|
| 교통 | | |
| 음식 | | |
| 직업 | | |
| 여가 | | |
| 경제 | | |

## 평가 계획

| 평가 기준 | 상 | 중 | 하 |
|-----------|-----|-----|-----|
| 일반화 활용 | 지형과 생활의 관계를 근거로 예측함 | 지형을 언급하지만 연결이 느슨함 | 지형과 무관하게 상상으로만 작성 |
| 정당화 | "~이기 때문에 ~할 것이다" 식으로 이유를 구체적으로 제시 | 이유를 제시하지만 막연함 | 이유 없이 결론만 제시 |
| 영역의 다양성 | 3개 이상 영역에서 생활 변화를 예측 | 1~2개 영역만 다룸 | 한 가지 측면만 언급 |

> 핵심: 정답 여부가 아니라 **정당화의 질**로 평가한다.
