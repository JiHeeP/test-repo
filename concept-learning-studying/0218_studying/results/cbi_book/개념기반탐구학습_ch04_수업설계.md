> **설계 날짜**: 2026-03-07
> **대상**: 3~4학년 / 과학

## 수업 개요

- **핵심 질문 (Essential Question)**: 가장 강력한 동물이란 어떤 것일까?
- **핵심 일반화 (Generalization)**: 환경의 변화는 생물의 생김새와 생활방식의 변화를 촉진한다
- **개념적 렌즈**: 인과
- **예상 차시**: 4차시

---

## 일반화 체계

| ID | 유형 | Key Concept | 일반화 |
|----|------|-------------|--------|
| G1 | 거시 | 인과 (렌즈) | 환경의 변화는 생물의 생김새와 생활방식의 변화를 촉진한다 |
| G2 | 미시 | 인과 | 서식지의 기후와 지형은 동물의 먹이 획득 방식과 이동 방식을 결정한다 |
| G3 | 미시 | 기능 | 동물의 신체 구조는 특정 환경에서 먹이를 얻고 위험을 피하는 기능을 수행한다 |
| G4 | 미시 | 연결 | 유사한 환경에 서식하는 서로 다른 동물들은 비슷한 생김새와 행동 패턴을 공유한다 |

> ⚠️ 미시 일반화 2~3개 추가 필요 (총 7~9개 권장)

---

## 차시별 흐름

### 1차시: 관계맺기 — "강한 동물은 어떤 동물인가?"
- **목표**: 학생의 사전 지식과 직관을 드러내고, `강하다`의 기준에 인지적 부조화를 일으킨다
- **활동**:
  1. 진술문 제시: `현재 살아 있는 동물들은 가장 강한 동물이다`
  2. 네 모퉁이 토론: `매우 그렇다 / 그렇다 / 아니다 / 매우 아니다` 중 한 곳에 서기
  3. 각자 `강한 동물은 ~이다. 왜냐하면 ~` 문장 쓰기
  4. 모퉁이별 이유 공유 후, 학급 전체에서 이유를 `힘 / 크기 / 속도 / 무서움 / 오래 살아남음 / 환경 적응` 같은 범주로 분류
- **준비물**: 네 구역 표지판, 포스트잇 또는 활동지, 판서용 차트
- **관계맺기 전략**: 네 모퉁이 토론 (의견 기반)

### 2차시: 인과 탐구 — 서식지와 동물 비교
- **목표**: 환경이 동물의 생김새와 생활 방식에 어떤 영향을 주는지 찾는다
- **활동**:
  1. 서로 다른 서식지의 동물 카드 비교
  2. `어디에 사는가 / 무엇을 먹는가 / 어떻게 움직이는가` 조사
  3. `환경이 무엇을 바꾸는가` 문장으로 정리
- **준비물**: 서식지별 동물 사진 카드, 조사 기록지
- **대응 일반화**: G2

### 3차시: 기능 탐구 — 생김새의 "왜"
- **목표**: 동물의 신체 구조와 생활 방식이 환경 속에서 어떤 기능을 하는지 이해한다
- **활동**:
  1. 발, 부리, 이빨, 털, 색 등 특징별 사례 보기
  2. `이 구조는 무엇을 하도록 돕는가?` 질문으로 기능 찾기
  3. `생김새-기능-환경` 연결표 만들기
- **준비물**: 특징별 동물 사진, 기능 연결표
- **대응 일반화**: G3

### 4차시: 연결 발견 + 되돌아보기
- **목표**: 유사한 환경의 동물들이 공유하는 패턴을 찾고 처음 생각과 비교한다
- **활동**:
  1. 환경별 동물 비교로 공통 패턴 찾기
  2. 처음 1차시 활동지 다시 읽기
  3. 네 모퉁이 토론 재실시 또는 같은 진술문 재판단
  4. `이제 내가 생각하는 강한 동물은 ~이다. 왜냐하면 ~` 다시 쓰기
- **준비물**: 1차시 활동지, 비교 자료
- **대응 일반화**: G4

| 환경-생김새-생활 방식 관계 이해 | 비교표, 연결표, 말하기 | 환경과 특징의 관계를 한 가지 이상 설명할 수 있는가 |
| 진술문 재작성 | `강한 동물은 ~이다. 왜냐하면 ~` 다시 쓰기 | 학생이 자기 언어로 일반화에 가까운 설명을 구성하는가 |
