# IB PYP 기능(Transdisciplinary Skills) 상세 정리

> **기준 문헌**: *Making the PYP happen: A curriculum framework for international primary education*  
> **판본 메모**: 2009 업데이트판 기준  
> **정리 날짜**: 2026-03-07  
> **정리 목적**: PYP의 `기능` 요소를 수업 설계와 평가 수준까지 바로 쓸 수 있게 정리

---

## 1. 먼저 구분할 것

PYP 2009에서 교육과정을 이루는 핵심 요소는 크게 `지식(knowledge)`, `개념(concepts)`, `기능(skills)`, `태도(attitudes)`, `행동(action)`이다.  
이 문서에서 다루는 것은 그중 `기능(skills)`이며, PYP 원문에서는 이를 **transdisciplinary skills**라고 부른다.

이 말은 중요하다. PYP의 기능은 특정 교과에만 묶인 기술이 아니라, **모든 탐구와 모든 교과를 가로질러 반복적으로 길러야 하는 기능**이라는 뜻이다.  
즉 PYP에서 기능은 `부록`이 아니라, 탐구가 실제로 일어나게 만드는 작동 장치에 가깝다.

이번 정리는 용어 혼동을 피하기 위해 **2009 원문 명칭**을 기준으로 쓴다.  
현장에서는 이를 `ATL(Approaches to Learning)` 언어로 읽는 경우가 많지만, 책과 직접 연결해 해석하려면 우선 2009 기능 체계를 정확히 붙잡는 편이 낫다.

---

## 2. PYP 기능 전체 구조 한눈에 보기

PYP 2009은 기능을 5개 기능군으로 제시한다.

| 기능군 | 핵심 질문 | 한 줄 요약 |
|--------|----------|------------|
| Thinking skills | 학생이 어떻게 생각을 조직하고 판단하는가? | 이해, 적용, 분석, 종합, 평가, 메타인지까지 포함하는 사고 기능 |
| Social skills | 학생이 다른 사람과 어떻게 함께 배우는가? | 책임, 협력, 갈등 해결, 집단 의사결정 같은 공동 학습 기능 |
| Communication skills | 학생이 어떻게 읽고, 듣고, 말하고, 쓰고, 표현하는가? | 언어적·비언어적 표현과 수용 기능 전체 |
| Self-management skills | 학생이 자기 몸과 시간과 행동을 어떻게 조절하는가? | 조직, 시간 관리, 안전, 건강, 행동 규범 등 자기조절 기능 |
| Research skills | 학생이 어떻게 질문하고, 찾고, 기록하고, 해석하고, 제시하는가? | 조사와 탐구를 실제로 수행하게 하는 핵심 기능 |

내가 보기에는 이 5개 기능군을 아래처럼 이해하면 가장 실용적이다.

1. `Thinking`은 머릿속 구조
2. `Social`은 함께 배우는 구조
3. `Communication`은 표현과 수용의 구조
4. `Self-management`는 학습 유지 장치
5. `Research`는 탐구 실행 장치

즉 PYP에서 탐구 수업은 `Research`만으로 굴러가지 않는다.  
조사하려면 질문을 세우는 `Thinking`, 협력하는 `Social`, 설명하는 `Communication`, 시간을 조절하는 `Self-management`가 같이 움직여야 한다.

## 3. 기능군별 상세 정리

## 3-1. Thinking skills

PYP 2009 원문에 제시된 Thinking skills 하위 요소는 다음과 같다.

| 하위 기능 | 한국어 풀이 | 수업에서 실제로 보이는 모습 |
|-----------|-------------|-----------------------------|
| acquisition of knowledge | 지식 획득 | 새 정보, 개념, 사실을 받아들이고 기억의 재료로 삼기 |
| comprehension | 이해 | 본 내용을 자기 말로 설명하고 뜻을 파악하기 |
| application | 적용 | 배운 개념이나 방법을 새 사례에 써 보기 |
| analysis | 분석 | 부분으로 나누어 비교하고 구조를 보기 |
| synthesis | 종합 | 여러 요소를 묶어 새로운 설명이나 구조를 만들기 |
| evaluation | 평가 | 근거를 가지고 판단하거나 선택하기 |
| dialectical thought | 변증법적 사고 | 상반된 관점이나 긴장을 함께 놓고 보기 |
| metacognition | 메타인지 | 내가 어떻게 생각하고 있는지 돌아보기 |

### 해설

- 이 기능군은 흔히 `비판적 사고`만 떠올리게 되지만, 실제로는 **지식 획득부터 메타인지까지 전 범위**를 포함한다.
- 특히 초등에서는 `analysis`, `synthesis`, `evaluation`만 강조하면 과하다. 오히려 `comprehension`과 `application`을 눈에 보이게 설계하는 편이 중요하다.
- `dialectical thought`는 단순히 찬반 토론이 아니라, 서로 다른 두 관점이 동시에 어느 정도 타당할 수 있음을 다루는 힘으로 읽는 편이 맞다.
- `metacognition`은 결과를 맞히는 것보다 `내가 왜 그렇게 생각했는가`를 설명하게 할 때 살아난다.

### 교사가 설계할 때 보는 포인트

| 질문 | 체크 포인트 |
|------|-------------|
| 학생이 단순히 찾기만 하는가, 아니면 해석하는가? | 분석·종합·평가 수준의 과제가 있는지 보기 |
| 학생이 자기 사고 과정을 말할 기회가 있는가? | 메타인지 문장틀, 회고 문항, 설명 활동 여부 확인 |
| 서로 다른 사례를 비교해 패턴을 보게 하는가? | 비교표, 분류, 개념 매핑, 패턴 찾기 여부 확인 |

## 3-2. Social skills

PYP 2009 원문에 제시된 Social skills 하위 요소는 다음과 같다.

| 하위 기능 | 한국어 풀이 | 수업에서 실제로 보이는 모습 |
|-----------|-------------|-----------------------------|
| accepting responsibility | 책임 받아들이기 | 맡은 역할을 수행하고 결과를 감당하기 |
| respecting others | 타인 존중 | 다른 의견, 순서, 기여를 존중하기 |
| cooperating | 협력하기 | 함께 일하며 과제를 나누고 조정하기 |
| resolving conflict | 갈등 해결 | 충돌을 말로 풀고 해결책을 찾기 |
| group decision making | 집단 의사결정 | 함께 선택 기준을 세우고 결정하기 |
| adopting a variety of group roles | 다양한 집단 역할 수행 | 기록자, 발표자, 조정자 등 역할을 바꾸어 맡기 |

### 해설

- PYP에서 협력은 `사이좋게 지내기` 정도가 아니다. **책임, 조정, 의사결정, 역할 전환까지 포함하는 학습 구조**다.
- 따라서 모둠 활동이 있다고 Social skills가 길러지는 것이 아니다. 역할과 의사결정 구조가 없으면 그냥 `같이 앉아 있는 것`에 그친다.
- `accepting responsibility`와 `adopting a variety of group roles`는 특히 중요하다. 초등 수업에서는 늘 같은 학생이 발표하고 같은 학생이 정리하는 구조가 굳기 쉽기 때문이다.
- `resolving conflict`는 생활지도 항목이 아니라, 탐구 과정에서 자료 선택이나 주장 충돌을 다루는 학습 기능으로 봐야 한다.

### 교사가 설계할 때 보는 포인트

| 질문 | 체크 포인트 |
|------|-------------|
| 모둠 활동에 실제 역할 구조가 있는가? | 역할 카드, 역할 순환, 역할별 산출물 여부 확인 |
| 의견 충돌이 생겼을 때 처리 장치가 있는가? | 기준표, 토론 규칙, 합의 절차 여부 확인 |
| 공동 결정이 필요한 순간이 있는가? | 조사 질문 선택, 자료 채택, 발표 구조 설계 여부 확인 |

## 3-3. Communication skills

PYP 2009 원문에 제시된 Communication skills 하위 요소는 다음과 같다.

| 하위 기능 | 한국어 풀이 | 수업에서 실제로 보이는 모습 |
|-----------|-------------|-----------------------------|
| listening | 듣기 | 타인의 말과 정보를 주의 깊게 받아들이기 |
| speaking | 말하기 | 생각과 정보를 구두로 표현하기 |
| reading | 읽기 | 글과 자료에서 의미를 파악하기 |
| writing | 쓰기 | 생각과 정보를 글로 조직하기 |
| viewing | 보기 | 이미지, 영상, 시각 자료를 해석하기 |
| presenting | 제시하기 / 발표하기 | 결과를 구조 있게 보여 주기 |
| non-verbal communication | 비언어적 의사소통 | 몸짓, 표정, 시각 자료, 배치 등으로 의미 전달하기 |

### 해설

- PYP의 communication은 국어 시간의 말하기/듣기만 뜻하지 않는다. **읽기, 쓰기, 보기, 발표, 비언어 표현까지 포함하는 다매체적 기능**이다.
- `viewing`이 따로 있다는 점이 중요하다. 초등 탐구 수업에서는 사진, 도표, 영상, 지도, 인포그래픽을 읽는 기능이 매우 자주 필요하다.
- `presenting`은 결과 발표 자체보다, **무엇을 어떤 순서로 보여 줄지 조직하는 힘**으로 보는 편이 맞다.
- `non-verbal communication`은 어린 학생일수록 중요하다. 말로 설명이 부족해도 그림, 몸짓, 배치로 의미를 전달할 수 있기 때문이다.

### 교사가 설계할 때 보는 포인트

| 질문 | 체크 포인트 |
|------|-------------|
| 학생이 읽기만 하는가, 아니면 보고 해석하는가? | 사진·지도·도표·영상 해석 활동 포함 여부 |
| 발표 전에 구조화 시간이 있는가? | 발표 틀, 문장틀, 시각 자료 설계 여부 확인 |
| 다양한 표현 채널이 허용되는가? | 말, 글, 그림, 표, 몸짓, 디지털 슬라이드 활용 가능 여부 |

## 3-4. Self-management skills

PYP 2009 원문에 제시된 Self-management skills 하위 요소는 다음과 같다.

| 하위 기능 | 한국어 풀이 | 수업에서 실제로 보이는 모습 |
|-----------|-------------|-----------------------------|
| gross motor skills | 대근육 기능 | 몸 전체를 사용하는 활동 수행 |
| fine motor skills | 소근육 기능 | 쓰기, 자르기, 조작하기 같은 정교한 활동 수행 |
| spatial awareness | 공간 인식 | 공간과 물체 배치를 이해하고 움직이기 |
| organization | 조직 | 자료, 도구, 기록을 정리하기 |
| time management | 시간 관리 | 주어진 시간 안에 과제를 계획하고 마치기 |
| safety | 안전 | 활동 중 안전 규칙을 지키기 |
| healthy lifestyle | 건강한 생활 방식 | 몸과 마음의 건강을 고려해 학습 지속하기 |
| codes of behaviour | 행동 규범 | 공동체 규칙과 기대를 지키기 |
| informed choices | 정보에 근거한 선택 | 이유를 알고 적절한 선택을 하기 |

### 해설

- 이 기능군은 자칫 `생활 습관` 정도로 축소되기 쉽지만, 실제로는 **학습을 유지 가능하게 하는 운영 기능**이다.
- 특히 `organization`과 `time management`는 프로젝트형 수업이나 조사 활동에서 매우 중요하다. 자료는 찾았는데 정리가 안 되고, 시간이 부족해 발표를 못 하는 문제가 여기와 직결된다.
- `informed choices`는 단순 생활지도가 아니라, 자료 선택, 주제 선택, 방법 선택을 근거 있게 하도록 만드는 기능이다.
- `gross motor`, `fine motor`, `spatial awareness`가 들어 있다는 점도 PYP다운 특징이다. 탐구는 책상 위 인지 활동만이 아니라, 실제 조작과 공간 활동까지 포함한다는 뜻이다.

### 교사가 설계할 때 보는 포인트

| 질문 | 체크 포인트 |
|------|-------------|
| 학생이 자료와 기록을 정리할 구조가 있는가? | 조사 기록지, 폴더 구조, 정리 규칙 여부 |
| 시간 관리 장치가 있는가? | 활동 시간 분할, 체크포인트, 중간 마감 여부 |
| 선택에 근거를 요구하는가? | `왜 이 자료/방법/주제를 골랐는가`를 묻는 문항 여부 |

## 3-5. Research skills

PYP 2009 원문에 제시된 Research skills 하위 요소는 다음과 같다.

| 하위 기능 | 한국어 풀이 | 수업에서 실제로 보이는 모습 |
|-----------|-------------|-----------------------------|
| formulating questions | 질문 형성 | 조사할 만한 질문을 만들기 |
| observing | 관찰 | 현상, 자료, 장면을 주의 깊게 보기 |
| planning | 계획 | 조사 순서와 방법을 짜기 |
| collecting data | 자료 수집 | 필요한 정보와 사례를 모으기 |
| recording data | 자료 기록 | 찾은 내용을 남기고 누락 없이 정리하기 |
| organizing data | 자료 조직 | 분류, 표, 범주화로 구조를 만들기 |
| interpreting data | 자료 해석 | 의미, 패턴, 관계를 읽어 내기 |
| presenting research findings | 연구 결과 제시 | 조사 결과를 다른 사람에게 전달하기 |

### 해설

- 이 기능군이 바로 `조사하기` 장의 핵심이다.
- 중요한 것은 순서다. PYP의 연구 기능은 `찾기`에서 시작하지 않는다. **질문 형성 → 관찰 → 계획 → 수집 → 기록 → 조직 → 해석 → 제시**의 흐름이다.
- 초등 수업에서 실제로 자주 빠지는 단계는 `recording`, `organizing`, `interpreting`이다. 자료를 찾기는 하는데 기록이 엉성하고, 구조화가 없어서, 결국 해석과 개념 연결로 못 올라가는 경우가 많다.
- 그래서 `조사하기`를 설계할 때는 결과물보다 먼저 **질문, 기록 방식, 조직 방식**을 보여 주는 편이 훨씬 낫다.

### 교사가 설계할 때 보는 포인트

| 질문 | 체크 포인트 |
|------|-------------|
| 학생 질문이 조사 가능한가? | 너무 크거나 모호하지 않은지 보기 |
| 자료 수집과 기록이 분리되어 있는가? | 찾기만 하고 기록하지 않는 구조인지 점검 |
| 자료 조직 단계가 있는가? | 표, 분류표, 비교표, 개념 지도 여부 확인 |
| 해석을 요구하는가? | `그래서 무엇이 보이는가` 질문이 있는지 보기 |
| 결과 제시 전에 피드백이 있는가? | 중간 점검, 컨퍼런스, 출구카드 여부 확인 |

## 4. 6장 `조사하기`와 직접 연결되는 핵심

`개념기반 탐구학습의 실천` 6장을 읽을 때 IB PYP 기능이 중요한 이유는 분명하다.  
그 장이 말하는 `조사하기`는 사실 수집 그 자체가 아니라, **예를 통해 개념을 보게 만드는 단계**이기 때문이다.  
그 일을 실제로 가능하게 하는 기능 묶음이 바로 PYP의 Research skills다.

특히 6장과 바로 연결되는 부분은 아래 5가지다.

| 6장 핵심 주장 | PYP 기능으로 풀면 | 수업 설계에서 바로 바꿀 수 있는 것 |
|---------------|------------------|-----------------------------------|
| 조사 자체가 목적이 아니다 | interpreting data, organizing data | 기록지에 `개념 연결` 칸 넣기 |
| 사실적 질문이 중요하다 | formulating questions | 질문 만들기 미니 활동 먼저 넣기 |
| 다양한 예를 탐색해야 한다 | collecting data, observing | 자료 출처와 사례 범주를 다양화하기 |
| 기능 개발이 병행되어야 한다 | research skills 전체 + thinking/communication/social 지원 | 결과만이 아니라 과정 기능을 함께 평가하기 |
| 형성평가가 필요하다 | recording, organizing, presenting 단계별 피드백 | 체크리스트, 루브릭, 출구카드, 상의 구조 넣기 |

내 기준으로 보면, 6장을 제대로 수업에 옮기려면 아래 질문을 먼저 던져야 한다.

1. 학생이 `무엇을 찾을지`보다 `무슨 질문을 할지`가 먼저 보이는가?
2. 학생이 `찾은 내용`만이 아니라 `어떻게 기록하고 조직했는지`가 남는가?
3. 학생이 마지막에 `사실`을 `개념`으로 다시 묶는 순간이 설계되어 있는가?

이 세 질문이 빠지면 조사 활동은 쉽게 `자료 모으기 행사`가 된다.

## 5. 수업 설계에 바로 쓰는 최소 기능 세트

PYP 기능 전체는 넓다. 초등 수업에서 한 차시나 한 단원에 다 넣으려 하면 오히려 흐려진다.  
그래서 실제 설계에서는 `이번 단원에서 반드시 보일 기능`을 먼저 좁히는 편이 좋다.

### 조사 중심 단원이라면 최소 이 6개는 잡는 것이 좋다

| 우선 기능 | 이유 | 학생 행동 증거 |
|-----------|------|----------------|
| formulating questions | 조사 방향이 여기서 결정됨 | 질문이 구체적이고 조사 가능하다 |
| collecting data | 실제 탐구의 재료를 모음 | 한 가지 이상 출처에서 사례를 찾는다 |
| recording data | 찾은 것을 잃지 않음 | 표, 메모, 기록지에 남긴다 |
| organizing data | 비교와 패턴 발견의 바탕 | 분류, 묶기, 비교표가 보인다 |
| interpreting data | 개념 연결의 핵심 | `무엇이 보이는가`를 설명한다 |
| presenting research findings | 학습을 공유하고 수정함 | 말, 글, 슬라이드, 포스터로 제시한다 |

### 여기에 붙이면 좋은 지원 기능

| 지원 기능군 | 붙이면 좋은 이유 |
|-------------|------------------|
| Thinking | 자료 해석과 패턴 읽기 질이 올라간다 |
| Communication | 조사 결과가 더 분명하게 보인다 |
| Social | 모둠 조사에서 역할과 책임이 살아난다 |
| Self-management | 시간 부족, 기록 누락, 정리 실패를 줄인다 |

## 6. 형성평가로 볼 수 있는 관찰 포인트

PYP 기능은 `배웠다/안 배웠다` 식으로 끝내기 어렵다.  
그래서 형성평가는 기능이 실제 행동으로 드러나는지 보는 방식이어야 한다.

| 기능 | 관찰 포인트 | 간단한 평가 장치 |
|------|-------------|------------------|
| formulating questions | 질문이 모호하지 않고 조사 가능하다 | 질문 점검 체크리스트 |
| collecting data | 출처가 한 종류에만 치우치지 않는다 | 자료 출처 기록표 |
| recording data | 메모가 빠지지 않고 다시 볼 수 있다 | 조사 기록지 |
| organizing data | 분류 기준이 있다 | 비교표, 범주표 |
| interpreting data | 사실에서 의미를 설명한다 | `그래서 무엇이 보이는가?` 출구카드 |
| presenting research findings | 핵심이 구조 있게 전달된다 | 발표 루브릭 |
| cooperating | 역할이 작동한다 | 모둠 역할 점검표 |
| metacognition | 자기 과정을 돌아본다 | 짧은 회고 문항 |

### 아주 실용적인 교사용 질문

수업 중에 교사가 아래 질문만 반복해도 기능이 보이기 시작한다.

1. `지금 네 질문은 조사할 수 있는 질문이니?`
2. `찾은 걸 어디에 남기고 있니?`
3. `그 자료를 왜 믿을 수 있니?`
4. `비슷한 것끼리 묶어 보면 뭐가 보이니?`
5. `이 사실이 어떤 개념과 연결되니?`
6. `지금 네가 하고 있는 방법은 효과적이니?`

이 질문들은 각각 `질문 형성`, `기록`, `자료 선택`, `조직`, `해석`, `메타인지`를 직접 건드린다.

## 7. 한국 초등 수업으로 번역할 때의 주의점

### 1. 기능을 `태도`와 섞지 않기

`협력한다`, `책임진다` 같은 말은 쉽게 생활지도 문장처럼 들린다.  
하지만 PYP 기능은 도덕적 덕목이 아니라 **학습을 수행하는 방법**이다.  
예를 들어 `cooperating`은 그냥 사이좋게 지내는 것이 아니라, 역할과 자료와 결정을 함께 다루는 기능이다.

### 2. 기능을 `결과물 평가`로만 보지 않기

조사 보고서가 깔끔하다고 기능이 길러진 것은 아니다.  
질문을 어떻게 만들었는지, 자료를 어떻게 조직했는지, 어떤 피드백 뒤에 수정했는지를 함께 봐야 한다.

### 3. 한 단원에 모든 기능을 다 넣으려 하지 않기

PYP 기능표는 `전체 지도`다. 실제 수업에서는 이 중 몇 개를 골라 선명하게 보는 편이 낫다.  
특히 조사 단원에서는 `Research + Thinking + Communication`의 핵심 몇 개를 먼저 잡는 것이 현실적이다.

### ==4. 기능은 문장으로 보이게 해야 한다==

학생이 실제로 기능을 썼는지 보려면, 활동 뒤에 문장틀이 필요하다.

예시:
- `내 질문은 ______이다.` → `Research skills: formulating questions`
- `내가 찾은 자료 중 중요한 것은 ______이다.` → `Research skills: collecting data`, `Thinking skills: evaluation`
- `이 자료를 고른 이유는 ______이다.` → `Self-management skills: informed choices`, `Thinking skills: evaluation`
- `비슷한 것끼리 묶어 보니 ______가 보였다.` → `Research skills: organizing data`, `Research skills: interpreting data`, `Thinking skills: analysis`
- `이 사실은 ______ 개념과 연결된다.` → `Research skills: interpreting data`, `Thinking skills: synthesis`

이런 문장이 있어야 기능이 관찰 가능해진다.

## 8. 지금 바로 써먹는 정리

한 줄로 줄이면 이렇다.

> **PYP 기능은 탐구를 굴러가게 만드는 실행 체계이고, 그중 6장 `조사하기`를 직접 떠받치는 것은 Research skills이다.**

조사 수업을 설계할 때는 최소한 아래 순서를 보이면 된다.

1. 질문 만들기
2. 자료 찾기
3. 자료 기록하기
4. 자료 조직하기
5. 의미 해석하기
6. 결과 제시하기

그리고 이 과정 전체를 `Thinking`, `Communication`, `Social`, `Self-management`가 옆에서 지탱한다고 보면 된다.
